# Interactive clothing rack

Berlaku untuk kategori **Gaun Wanita** dan **Jas Pria**, sekaligus menjadi Hero Showcase utama.

## Rak gantung perspektif

Rel gantungan besi metalik dengan pakaian tergantung. Item aktif menghadap penuh `rotateY(0deg) scale(1.08)`; item lain menyamping dengan `perspective(1200px) rotateY(-42deg) scale(0.86)` dan `brightness(0.92)`. Dukung klik langsung, horizontal scroll/wheel, drag/swipe, panah ← → dan keyboard arrow.

## Panel editorial kanan

Indeks `01 / XX`, kategori, judul serif, harga IDR, deskripsi singkat, tabel **MATERIAL**, **COLOR**, **SIZE**, tombol **INSPEKSI BAJU**, dan **VIEW DETAILS →**. Detail harus memakai katalog asli.

## Stage Focus Mode

Klik baju aktif atau **INSPEKSI BAJU** memburamkan rak `blur(11px)`; baju terpilih melayang membesar di tengah. **Hangtag Warna** bergantung di bahu kanan: tali, kartu kertas vertikal dengan ayunan lembut, swatch yang mengubah warna pakaian secara halus. Di bawah tersedia **FRONT | BACK**, pilihan ukuran dan quick-add ke keranjang. Jangan mengklaim foto belakang asli jika aset belakang tidak tersedia. Escape, tombol tutup dan pengembalian focus harus bekerja.
